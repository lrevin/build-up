# database

BuildUp의 DB 설계와 인증·보안 참고 코드를 공유하는 폴더입니다.

- `erd/`: Flyway V11 기준 ERD 문서와 이미지
- `jpa/`: 최신 Entity·Enum·Converter·Repository와 데이터 사전
- `migrations/`: Flyway V1~V11 SQL
- `security/`: 비밀번호, JWT, Refresh Token, 인증 응답 참고 코드

실행 가능한 전체 백엔드 프로젝트는 [buildup_backend](https://github.com/hiallu60/buildup_backend)에서 확인합니다. 이 폴더에는 DB·보안 구조를 이해하는 데 필요한 파일만 복사해 둡니다.
